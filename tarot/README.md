# 🔮 고민타파 타로 — 부천시청소년상담복지센터 청소년 타로 프로그램

## 프로젝트 소개
청소년의 고민(학업·친구·진로·감정)을 78장 타로카드를 기반으로 신비롭고 친근하게 해석해 주는 **청소년 맞춤 타로 상담 웹앱**입니다.  
타로카드로도 해결되지 않는 고민은 **부천시청소년상담복지센터(032-325-3002)** 전문 상담사와 연결됩니다.

---

## ✅ 구현된 기능

| 기능 | 설명 |
|------|------|
| 🌟 인트로 화면 | 신비로운 별빛 배경, 유성 애니메이션, 황금 버튼 |
| ✍️ 고민 입력 | 최대 200자 텍스트 입력, 글자 수 카운터 |
| 🎴 부채형 카드 덱 | 78장 카드를 부채형으로 펼쳐 직접 클릭·선택 (호버 시 카드 올라옴) |
| 🔮 로딩 화면 | 마법 크리스탈 스핀 + 메시지 순환 |
| 📖 결과 화면 | 3카드 스프레드(과거·현재·미래) 카드 표시 + 종합 조언 |
| 🧠 고민 주제 분석 | 7개 주제(친구/연애/학업/진로/가족/스트레스/자아) 키워드 자동 분류 |
| 💌 마음이 응원 메시지 | 고민 주제에 맞춤 응원 메시지 생성 |
| 📜 종합 조언 연동 | 고민 주제별 맞춤 인트로·아웃트로·상담 배너 문구 |
| 💜 상담 안내 | 주제별 맞춤 문구 + 032-325-3002 전화 연결 버튼 |
| 🎆 파티클 효과 | 버튼 클릭 시 화려한 파티클 버스트 |
| ✨ 별빛 캔버스 | 200개 별 + 유성 애니메이션 (Canvas API) |
| 📱 반응형 디자인 | 모바일/태블릿/데스크톱 반응형 부채형 카드 + 슬롯 레이아웃 |

---

## 🔧 최근 수정 사항 (v2.1)

- **오류 수정**: 구버전 `app.js` 제거 (HTML과 호환되지 않는 DOM 참조 충돌 해결)
- **부채형 카드 개선**:
  - `overflow: visible`로 변경 → 호버 시 카드가 잘리지 않음
  - 반응형 카드 크기 (모바일 44×68, 태블릿 56×88, 데스크톱 68×108)
  - 반응형 부채 반지름·각도 자동 계산
  - 카드 등장 애니메이션 (`fanCardAppear`) 추가
  - 선택된 카드가 위로 올라와서 구별되도록 개선
  - 터치 디바이스 대응 (`:active` 스타일 추가)
  - 비활성 카드에 `pointer-events: none` 추가
- **모바일 반응형 강화**: 슬롯 크기 축소, 카드 영역 여백 최적화

## 📁 파일 구조

```
index.html          ← 메인 HTML (5개 섹션 싱글 페이지)
css/
  style.css         ← 전체 스타일 (신비로운 보라·금색 테마)
js/
  tarot-data.js     ← 타로카드 78장 데이터 + 포지션·수트 정의
  main.js           ← 화면 전환, 부채형 뽑기 로직, 결과 생성 (v2)
```

---

## 🔗 진입점 및 흐름

```
/ (index.html)
  ↓ [인트로] → 고민타파 타로 보기 버튼
  ↓ [고민 입력] → 텍스트 입력 + 주제 자동 분석
  ↓ [카드 뽑기] → 부채형 78장 덱에서 3장 직접 클릭 선택
  ↓ [로딩] → 3초 마법 로딩 화면
  ↓ [결과] → 3카드 스프레드 해석 + 종합 조언 + 상담 안내
```
